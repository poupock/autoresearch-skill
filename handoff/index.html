Инструкция для коллеги

Видео → транскрипт → описание → обложка

Как получить готовое описание к YouTube-ролику и промт для обложки за 20 минут, не привлекая автора. Пайплайн, все шаги, точные промт-шаблоны для вставки в Claude, и что делать, когда что-то пошло не так.

1 pdf-ish read~25 минут первый прогон~10 минут дальше

00Как это устроено

Три инструмента, четыре шага. Whisper делает текст из видео, Claude пишет описание и собирает промт для обложки, генератор картинок рисует саму обложку.

Что за инструменты

  • Whisper — локальный распознаватель речи от OpenAI. Мы используем его через удобное десктопное приложение: MacWhisper на Mac, Buzz на Windows/Linux. Всё считается на твоём компьютере, файлы никуда не уходят.
  • Claude Desktop — официальное приложение Anthropic. Ключевая функция для нас: подключение к папке через MCP, чтобы Клод сам читал файлы, а не через копипаст.
  • Midjourney (в Discord) или ChatGPT (DALL·E) — только для последнего шага, генерации самой картинки по готовому промту.
*

В нашей команде «Вайсбер» — это Whisper. Если у тебя другой транскрипционный инструмент — просто пропусти шаг A.1 и используй свой; всё остальное работает так же.

AУстановка

Один раз. Дальше не трогаешь.

1

A.1 — Транскрипционный инструмент (Whisper)

Mac: скачай MacWhisper — goodsnooze.com/macwhisper. Открой .dmg, перетащи в Applications, запусти. При первом запуске он предложит скачать модель — выбери medium (для русского это разумный баланс) или large-v3 если хочется максимум качества.

Windows / Linux: скачай Buzz — github.com/chidiwilliams/buzz/releases. Ставится как обычный .exe. Модель medium — из настроек.

Скрин 1 Главное окно MacWhisper / Buzz после установки: слева пустой список файлов, справа панель настроек с полями Model, Language и кнопкой Transcribe.

Настройки на один раз

  • Model: medium или large-v3.
  • Language: Russian или Auto, если языки разные.
  • Output format: .txt обязательно, дополнительно .srt — про запас, если понадобятся тайм-коды.
2

A.2 — Claude Desktop

Скачай приложение с claude.ai/download, войди в аккаунт.

Теперь дадим ему доступ к рабочей папке. Открой Settings → Developer → Edit Config — откроется файл claude_desktop_config.json. Вставь блок:

claude_desktop_config.json 
{
  "mcpServers": {
    "filesystem": {
      "command": "npx",
      "args": [
        "-y",
        "@modelcontextprotocol/server-filesystem",
        "/Users/YOU/Projects/covers"
      ]
    }
  }
}

Замени путь на свой (Windows: C:\\Users\\YOU\\Projects\\covers, с двойными обратными слэшами). Полностью перезапусти Claude Desktop.

Скрин 2 Настройки Claude Desktop, вкладка Developer. Открытый в редакторе claude_desktop_config.json — видно вставленный блок mcpServers.filesystem.
!

Node.js обязателен — команда npx работает только если установлен Node. Проверь: в терминале node -v. Если нет — поставь nodejs.org LTS.

3

A.3 — Проверка

Открой в Claude Desktop новый чат и напиши:

Проверочный запрос
Покажи содержимое папки, к которой у тебя есть доступ.

Клод должен вывести список файлов из папки. Если нет — проверь, что перезапустил приложение и что путь в конфиге совпадает с реальным.

BСтруктура папки

Порядок, к которому Клод ждёт файлы. Один раз собираешь — дальше только докидываешь новые видео.

covers/ ├── videos/ ← сюда кладёшь новые ролики (.mp4, .mov) ├── transcripts/ ← сюда сохраняешь .txt из Whisper ├── examples/ │ ├── descriptions.md ← 3–5 прошлых удачных описаний │ └── cover-prompts.md ← 3–5 прошлых промтов к обложкам └── output/ ├── descriptions/ ← сюда попадают готовые описания └── cover-prompts/ ← сюда попадают готовые промты

Оба файла в examples/ — обычный текст. Разделяй записи пустой строкой. Пример:

examples/descriptions.md
Три века назад в Петербурге зажгли газовые фонари — задолго до того, как…
[дальше — целиком описание, как оно было опубликовано]

Второе описание. Другая тема, тот же голос.
[и так далее]
*

Правило: как только новое описание получилось хорошим — добавь его в examples/descriptions.md. Клод копирует стиль оттуда, поэтому чем свежее примеры — тем точнее попадание.

CПайплайн на каждое видео

Четыре шага. С третьего раза идёт по памяти.

1

C.1 — Транскрибация

  1. Положи новое видео в covers/videos/.
  2. В MacWhisper / Buzz: File → Add, выбери файл.
  3. Проверь: модель, язык, вывод .txt.
  4. Нажми Transcribe. Ждать: 10-минутное видео на medium ≈ 2–3 минуты, на large-v3 ≈ 6–8.
  5. Сохрани готовый .txt в covers/transcripts/. Имя файла = имя видео (без пробелов, безопаснее с -).
Скрин 3 MacWhisper во время транскрибации: индикатор прогресса, ниже — текст, который появляется по мере распознавания. Кнопка Export → Text (.txt) в правом верхнем.
2

C.2 — Описание видео

В Claude Desktop открой новый чат. Вставь промт D.1, заменив <имя-файла> на настоящее имя транскрипта. Клод сам прочитает файлы примеров и транскрипта, вернёт описание.

Проверь глазами, поправь, если что, сохрани в output/descriptions/<имя-файла>.md.

*

Если тон промахнулся — попроси конкретно: «сделай короче на треть», «убери восклицательный знак», «первое предложение переделай так, чтобы начиналось с факта, а не с вопроса». Не пиши «сделай лучше» — Клод не поймёт, что именно.

3

C.3 — Промт для обложки

В том же чате (Клод помнит контекст) или в новом — вставь промт D.2. Клод сравнит с примерами и вернёт готовый промт одной строкой.

Сохрани в output/cover-prompts/<имя-файла>.txt.

4

C.4 — Собственно обложка

  • Midjourney: в Discord набери /imagine и вставь промт целиком (в конце должен быть --ar 16:9). Получишь сетку из 4 вариантов, дальше U1..U4 (апскейл), V1..V4 (вариации).
  • ChatGPT / DALL·E: в чате «Сгенерируй по этому промту, соотношение 16:9», вставь.

Выбери один, при необходимости — попроси вариации той же композиции с другим освещением или цветом. Готово.

DПромт-шаблоны

Оба промта — просто скопировать в чат Claude Desktop, подставить имя файла.

D.1 — Описание видео 
Ты помогаешь мне писать описание к YouTube-видео в моём голосе.

1) Прочитай мои прошлые описания и переними стиль, длину, ритм, тон:
   файл: examples/descriptions.md

2) Прочитай транскрипт нового видео:
   файл: transcripts/<имя-файла>.txt

3) Напиши описание в том же стиле.

Правила:
- Длина: не длиннее самого длинного примера.
- Начинай с крючка (факт, образ, вопрос), не с «в этом видео».
- Эмодзи — только если они есть в примерах.
- CTA в конце — только если он есть в примерах.
- Никаких списков и подзаголовков, если их нет в примерах.

Выведи только текст описания, без комментариев и без метки «Описание:».
D.2 — Промт для обложки (Midjourney) 
Ты собираешь промт для обложки видео (Midjourney).

1) Прочитай мои прошлые обложечные промты:
   файл: examples/cover-prompts.md

2) Прочитай описание нового видео:
   файл: output/descriptions/<имя-файла>.md

3) Собери один промт для обложки в том же стиле и грамматике.

Правила:
- Один центральный визуальный образ, читаемый на превью размером с ноготь.
- Тот же визуальный язык, что в примерах (палитра, шрифт, атмосфера, техника).
- Никаких лиц публичных людей, водяных знаков, логотипов, текста.
- В конце добавь параметры: --ar 16:9 --v 6 --style raw

Выведи только промт, одной строкой, без комментариев.

EЧто делать если

Короткий список типовых косяков и их починки.

Whisper пишет ерунду в русских словах

Переключи модель с small/medium на large-v3. Если и на large-v3 ошибается — явно поставь Language: Russian вместо Auto. На тихой записи или сильном фоне помогает предварительная нормализация звука в любом аудиоредакторе.

Claude отвечает «у меня нет доступа к файлам»
  • Проверь, что полностью закрыл и заново открыл Claude Desktop (не свернул — а именно вышел).
  • В Settings → Developer в статусе должен быть filesystem: connected.
  • Путь в конфиге — абсолютный (начинается с / на Mac или C:\\ на Windows) и существует.
  • Проверь, что установлен Node.js: в терминале node -v.
Описание получилось не в стиле — «слишком общо», «не мой голос»

Причина почти всегда одна: в examples/descriptions.md мало или устаревшие примеры. Добавь ещё 2–3 недавних удачных описания и перезапусти шаг C.2. Правильные примеры важнее умных инструкций.

Обложка получается «мыльной», без деталей

Добавь в конец промта sharp focus, high detail, cinematic lighting. Если промт получается длинный — сначала выкинь общие слова («beautiful», «amazing»), они ничего не добавляют.

Клод пишет слишком длинно / слишком коротко

В шаблоне D.1 замени пункт «Длина: не длиннее самого длинного примера» на «Длина: строго не более N слов». Если наоборот — «не менее N слов».

MacWhisper падает на длинных стримах (60+ минут)

Разрежь файл на куски по 30–40 минут любым видеоредактором (или командой ffmpeg -i in.mp4 -c copy -segment_time 1800 -f segment out%03d.mp4). Транскрибируй каждый кусок, потом склей .txt-файлы в один.

Хочу дать Клоду сразу несколько видео

Работает: положи все транскрипты в transcripts/, и в промте D.1 замени «файл: transcripts/<имя-файла>.txt» на «файлы: все .txt в папке transcripts/». Клод пройдётся по каждому и выдаст пачку описаний.

Handoff for a teammate

Video → transcript → description → cover

How to turn a YouTube video into a finished description and a cover-art prompt in 20 minutes without pulling in the author. The pipeline, every step, the exact prompt templates to paste into Claude, and what to do when something goes sideways.

One read~25 min first run~10 min after that

00How the pipeline works

Three tools, four steps. Whisper turns video into text, Claude writes the description and assembles the cover prompt, an image generator draws the cover.

The tools

  • Whisper — OpenAI's local speech-to-text. We run it through a friendly desktop app: MacWhisper on Mac, Buzz on Windows / Linux. Everything runs on your machine; files never leave it.
  • Claude Desktop — Anthropic's official app. The key feature for us: MCP filesystem access, so Claude reads your files directly instead of via copy-paste.
  • Midjourney (in Discord) or ChatGPT (DALL·E) — only for the last step, drawing the cover from the finished prompt.
*

On our team "Wisber" refers to Whisper. If you use a different transcription tool, skip step A.1 and use yours; everything downstream is the same.

ASetup

One-time. Don't touch it afterwards.

1

A.1 — Transcription tool (Whisper)

Mac: get MacWhisper from goodsnooze.com/macwhisper. Open the .dmg, drag it to Applications, launch. On first run it will download a model — pick medium (sensible default) or large-v3 for best quality.

Windows / Linux: get Buzz from github.com/chidiwilliams/buzz/releases. Installs like any .exe. Pick the model from Preferences.

Screen 1 MacWhisper / Buzz main window right after install: empty file list on the left, settings panel on the right with Model, Language and a Transcribe button.

One-time settings

  • Model: medium or large-v3.
  • Language: your target language, or Auto for mixed content.
  • Output format: .txt is required, plus .srt as a fallback if you ever need timecodes.
2

A.2 — Claude Desktop

Download from claude.ai/download, sign in.

Now give it access to your working folder. Open Settings → Developer → Edit Config — this opens claude_desktop_config.json. Paste this block:

claude_desktop_config.json 
{
  "mcpServers": {
    "filesystem": {
      "command": "npx",
      "args": [
        "-y",
        "@modelcontextprotocol/server-filesystem",
        "/Users/YOU/Projects/covers"
      ]
    }
  }
}

Replace the path with your actual folder (Windows: C:\\Users\\YOU\\Projects\\covers — double backslashes). Fully quit and relaunch Claude Desktop.

Screen 2 Claude Desktop Settings, Developer tab. The config file open in an editor showing the mcpServers.filesystem block you just pasted.
!

Node.js is required — npx only works with Node installed. Check in a terminal: node -v. If missing, install LTS from nodejs.org.

3

A.3 — Sanity check

Open a new chat in Claude Desktop and type:

Sanity check
List the contents of the folder you have access to.

Claude should list your files. If not, check that you fully quit and reopened the app and that the path in the config actually exists.

BFolder layout

The layout Claude expects. Build it once, then only drop in new videos.

covers/ ├── videos/ ← drop new videos here (.mp4, .mov) ├── transcripts/ ← Whisper .txt files land here ├── examples/ │ ├── descriptions.md ← 3–5 past descriptions that landed well │ └── cover-prompts.md ← 3–5 past cover prompts └── output/ ├── descriptions/ ← finished descriptions land here └── cover-prompts/ ← finished cover prompts land here

Both files in examples/ are plain text. Separate entries with a blank line:

examples/descriptions.md
Three centuries ago Petersburg lit its gas lamps — long before…
[the full description as it was published]

Second description. Different topic, same voice.
[and so on]
*

Rule: every time a new description turns out well — add it to examples/descriptions.md. Claude copies style from there, so fresher examples = sharper matches.

CPer-video workflow

Four steps. Muscle memory by the third video.

1

C.1 — Transcribe

  1. Drop the new video into covers/videos/.
  2. In MacWhisper / Buzz: File → Add, pick the file.
  3. Verify model, language, .txt output.
  4. Hit Transcribe. Timing: a 10-min clip on medium ≈ 2–3 min, on large-v3 ≈ 6–8 min.
  5. Save the .txt into covers/transcripts/. Filename = the video's name (no spaces — use -).
Screen 3 MacWhisper mid-transcription: progress bar, text appearing as it's recognized, and the Export → Text (.txt) button in the top-right corner.
2

C.2 — Description

Open a new chat in Claude Desktop. Paste prompt D.1, replacing <filename> with the real transcript name. Claude reads the example and transcript files itself and returns a description.

Read it, tweak if needed, save to output/descriptions/<filename>.md.

*

If the tone is off, ask specifically: "make it a third shorter", "drop the exclamation mark", "redo the first sentence to open with a fact, not a question". Don't say "make it better" — Claude has no idea what that means.

3

C.3 — Cover prompt

In the same chat (Claude keeps context) or a new one, paste prompt D.2. Claude compares to the examples and returns a single-line prompt.

Save to output/cover-prompts/<filename>.txt.

4

C.4 — The actual cover

  • Midjourney: in Discord type /imagine and paste the full prompt (it must end with --ar 16:9). You get a 4-image grid — then U1..U4 to upscale, V1..V4 for variations.
  • ChatGPT / DALL·E: "Generate this prompt at 16:9 aspect ratio", paste.

Pick one, ask for variations of the same composition with different lighting or palette if needed. Done.

DPrompt templates

Both prompts — just paste into a Claude Desktop chat, swap the filename.

D.1 — Video description 
You help me write YouTube video descriptions in my voice.

1) Read my past descriptions and pick up the style, length, rhythm, tone:
   file: examples/descriptions.md

2) Read the transcript of the new video:
   file: transcripts/<filename>.txt

3) Write a description in the same style.

Rules:
- Length: no longer than the longest example.
- Open with a hook (fact, image, question), not "in this video".
- Emoji only if the examples use them.
- CTA at the end only if the examples have one.
- No bullet lists or subheadings unless the examples use them.

Output only the description text — no commentary, no "Description:" label.
D.2 — Cover prompt (Midjourney) 
You assemble a cover-art prompt for a video (Midjourney).

1) Read my past cover prompts:
   file: examples/cover-prompts.md

2) Read the new video's description:
   file: output/descriptions/<filename>.md

3) Assemble one cover prompt in the same style and grammar.

Rules:
- One central visual, readable at thumbnail size.
- Same visual language as the examples (palette, typography, mood, technique).
- No faces of public figures, no watermarks, no logos, no text.
- End with: --ar 16:9 --v 6 --style raw

Output only the prompt, on one line, no commentary.

ETroubleshooting

Short list of the usual snags and how to unstick them.

Whisper mangles words in my target language

Switch the model from small/medium to large-v3. If large-v3 still gets it wrong, set Language explicitly instead of Auto. For quiet recordings or heavy background noise, normalize the audio in any audio editor first.

Claude says "I don't have access to files"
  • Fully quit and reopen Claude Desktop (not just close the window — quit the app).
  • In Settings → Developer, the connector should show filesystem: connected.
  • The path in the config must be absolute (starts with / on Mac or C:\\ on Windows) and must exist.
  • Check Node.js is installed: node -v in a terminal.
Description feels off — "too generic", "not my voice"

Almost always the same cause: examples/descriptions.md is thin or stale. Add 2–3 recent good descriptions and rerun step C.2. Right examples beat clever instructions.

Cover comes out blurry, low on detail

Append sharp focus, high detail, cinematic lighting to the prompt. If the prompt is getting long, first drop the empty adjectives ("beautiful", "amazing") — they carry no weight.

Claude writes too long / too short

In D.1 replace "Length: no longer than the longest example" with "Length: strictly at most N words". Or vice versa: "at least N words".

MacWhisper crashes on long streams (60+ min)

Slice the file into 30–40-minute chunks in any video editor (or with ffmpeg -i in.mp4 -c copy -segment_time 1800 -f segment out%03d.mp4). Transcribe each chunk, then concatenate the .txt files.

I want to hand Claude several videos at once

Works: put all the transcripts into transcripts/, and in D.1 replace "file: transcripts/<filename>.txt" with "files: every .txt inside transcripts/". Claude will iterate and hand you a batch of descriptions.

Инструкция для внутреннего использования. Правь examples/ — правишь стиль. Internal handoff. To change the voice, change the files in examples/.
